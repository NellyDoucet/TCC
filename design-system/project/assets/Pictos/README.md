# Pictos

- `attention-triangle.png` : panneau d'avertissement rouge avec point d'exclamation blanc et ombre grise. Utilisé par le composant Attention, à gauche du texte, 64 à 140 px de large.
- `fleche-courbe-teal.png` : flèche courbe épaisse en `teal` (#55a7a8), pointant vers la gauche. Utilisée par le composant SchemaFleches : une fois telle quelle pour la branche de gauche, une fois retournée horizontalement (`transform: scaleX(-1)`) pour la branche de droite.
