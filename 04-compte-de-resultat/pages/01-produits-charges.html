#1 Le Compte de Résultat

Le compte de résultat permet de déterminer le résultat de l'entreprise : le bénéfice ou la perte.

« Est-ce que j'ai gagné ou perdu de l'argent ? »

Il reprend l'ensemble des opérations de gestion :

  • Les produits
  • Les charges

→ Les produits

Ensemble des opérations entraînant un enrichissement de l'entreprise.

On distingue :

  • les produits d'exploitation (notamment les ventes de biens et de services)
  • les produits financiers
  • les produits exceptionnels

Précisions concernant les ventes de biens

Si les biens sont revendus dans l'état où ils ont été achetés, ils sont appelés

marchandises

Si les biens ont été fabriqués par l'entreprise, ils sont appelés

produits finis

→ Les charges

Ensemble des opérations entraînant un appauvrissement de l'entreprise.

On distingue :

  • les charges d'exploitation (notamment les achats de biens (autres que les immobilisations) et de services, les impôts et taxes, les salaires…)
  • les charges financières
  • les charges exceptionnelles

Précisions concernant les achats de biens

Si les biens sont destinés à être revendus, ils sont appelés

marchandises

Si les biens sont destinés à la fabrication de produits finis, ils sont appelés

matières premières

Si les biens sont destinés à être utilisés par l'entreprise, ils sont appelés

matières ou fournitures
